# OpenCode 工作台

OpenCode 使用仓库根目录的 [`AGENTS.md`](../AGENTS.md) 作为项目规则真源。

开始任务前读取 [`AGENTS.md`](../AGENTS.md)，再按任务范围读取 `docs/standards/`、`docs/features/`、`docs/plans/`、`docs/designs/`、源码和测试。本目录只登记 OpenCode 专属配置或命令，不复制长期规则。

项目工程方法入口：[pstack技能目录](../.ai/pstack/CATALOG.md)。调用尺度、权限和宿主适配遵循根AGENTS及目录链接的适配说明；本文件只做入口。
