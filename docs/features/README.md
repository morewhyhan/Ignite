# Features

这里存放 Ignite 的产品或业务需求规格。一个业务模块对应一个文件；模板整体定位见
[`product.md`](./product.md)，可运行参考纵向切片见 [`tasks.md`](./tasks.md)。

每份规格至少包含：

- 业务背景和目标
- 模块边界
- 字段清单和校验规则
- 页面/原型链接或说明
- Given/When/Then 验收标准
- 增量需求或对存量模块的变更说明

当前规格：[`product.md`](./product.md)、[`tasks.md`](./tasks.md)、[`auth.md`](./auth.md)。

模板见 [`_template.md`](./_template.md)。
