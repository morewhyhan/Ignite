# Ignite 功能规格：任务领域规则

## 背景与目标

任务标题与归属规则目前分散在路由校验与数据库约束中。
本规格要求这些规则集中到领域层，由领域函数统一裁决。

## 用户行为与边界

| 使用者与条件 | 动作或输入   | 观察结果              | 重要权限或失败边界     | 已有依据             |
| ------------ | ------------ | --------------------- | ---------------------- | -------------------- |
| 已登录用户   | 创建任务     | 标题去空格后 1–200 字 | 超长或空白拒绝         | 用户 2026-11-06 指令 |
| 已登录用户   | 修改他人任务 | 视为不存在            | 返回 404，不泄露存在性 | 用户 2026-11-06 指令 |

## 模块边界

- 规格：docs/features/spec-closure-domain.md
- 领域：src/server/domain/task.ts
- 路由：src/server/api/routes/tasks/index.ts
- 断言：tests/contracts/task-domain.test.ts

## 业务规则

- R1（REQ-SPEC-011）：任务规则由领域层统一裁决，路由不得重复判断。
- R2：标题去空格后长度必须在 1–200 之间。
- R3：非所有者访问按不存在处理。
- R4：更新请求至少提供一个可更新字段。

## 权限、错误与缓存

- 领域函数接收当前用户 id，不接受客户端传入的 userId。
- 非所有者访问返回 404，与不存在不可区分。

## 数据变化与回退

- 不修改数据库结构，无迁移。
- 回退方式为删除领域文件并恢复路由原实现。

## 原型与交互

- 不涉及界面变化。

## 非目标

- 不处理认证域的规则迁移。
- 不引入 Repository 接口或 DTO 转换。

## 验收标准

- AC-SPEC-011（REQ-SPEC-011）：Given 一个已登录用户 When 提交空白标题、超长标题、他人任务或空更新 Then 领域函数分别拒绝并给出对应错误，其余情况成功。
