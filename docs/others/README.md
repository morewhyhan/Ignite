## 模块说明（§8.1）

- 模块目标：本目录在开发闭环中负责什么。
- 输入：哪些信息可以进入本目录。
- 输出：必须交给哪个目录什么结果。
- 责任与非责任：哪类信息只能由本目录维护，哪些不能写进来。
- 内部结构：必须包含哪些章节或字段。
- 规则与事实源：哪些条件必须成立，判断现状依据什么。
- 验收标准：怎样判断本目录写对了。
- 交接：上游和下游怎样使用本目录的结果。
