## 模块说明（§8.1）

- 模块目标：保存决策、验收结论与运行证据，使结论可以被第三方复核。
- 输入：计划产出的运行记录、审查、决策与发布结果。
- 输出：ADR、账本、报告、运行清单。
- 责任与非责任：本目录只保存可追溯的记录；不复制实现细节，不定义需求。
- 内部结构：ADR 编号、账本条目、报告章节、证据目录。
- 规则与事实源：编号全仓唯一，引用必须能解析到真实文件或运行。
- 验收标准：每条结论都能点到计划编号、运行记录与提交。
- 交接：发布验收与本目录的证据绑定；报告供外部读者复核。
