# 原始输入资料

本目录按需保存较长或多份需求来源的原文，供 Feature 和 Plan 回查。短需求原话直接写在 Plan 的原始目标核对表，不必另建文件。

保存材料时保留原文和可追溯来源。记录文件名、来源链接或提供方，以及影响本轮判断的版本或日期；不要在原文上直接改写。来源更新且会影响已确认的目标时，保留旧版本并另存新版本，再由对应 Feature 或 Plan 说明采用哪一版。

输入资料只证明来源内容，不是产品规格或任务状态。确认后的用户行为和验收写入 [Feature](../../features/README.md)，本轮目标、范围和未决事项写入 [Plan](../../plans/README.md)。不在本目录维护处理进度、完成勾选或第二份需求状态。
